# JEV 相关性判断规则

筛选目标是人形机器人全身控制与柔顺运动跟踪。判断对象是论文的研究贡献和任务证据；humanoid、whole-body control 和 Unitree G1 都出现在判断条件中，但关键词或平台名本身不构成通过依据。

## 六项兴趣

| 方向 | 判定内容 | 权重 |
| --- | --- | --- |
| 人形移动与全身行为 | 双足移动、平衡、全身协调、移动操作 | 1.0 |
| 全身控制 | 浮动基、肢体或多接触的协调控制，支持传统与学习方法 | 1.0 |
| 柔顺与力交互控制 | 人形上的柔顺、阻抗、导纳、刚度调制和力位控制；上肢或末端柔顺也可相关 | 1.0 |
| 动作追踪与模仿 | 人形参考动作跟踪、模仿、重定向、运动过渡、遥操作 | 1.0 |
| 物理运动与跨本体表征 | 物理角色控制、运动规划、运动先验、人到人形的运动或动作表征 | 0.75 |
| 人体运动感知 | 人体关节姿态、相对身体段朝向、动作捕捉，如 IMU 或相机方法 | 0.75 |

当前综合相关性为各项“判断分 × 兴趣权重”的最大值，达到 0.60 且未触发排除条件才进入下一步。0.75 权重的相关方法，需要对应判断分达到 0.80 才能单独过门槛。机构偏好与质量代理评分在之后进行，不参与这些问题的判断。

## 平台与任务的关系

- G1、H1 等平台名可以帮助确认人形本体。其他人形或双足平台同样符合范围，不设品牌优待。
- 用 G1 做全身跟踪、移动操作、平衡或柔顺控制，按对应研究任务判断。
- 仅用 G1 的一只手臂做普通桌面抓取、将其当相机载体，或者只在引用、数据来源和未来工作里提到它，不足以证明上述任务相关。
- 人形上肢柔顺控制属于独立的柔顺方向，不要求论文一定涉及行走。普通机械臂上的柔顺方法，若没有人形应用证据，则不属于当前直接方向。
- 区分产生或控制身体动作的方法，与只预测图像的视频模型。人到人形、用于策略控制的动作表征可以进入较低权重的方法方向；仅用现有控制 token 生成视频不因此入选。
- 论文标题和摘要缺少关键实验信息时，不根据项目印象、作者名气或潜在未来应用补造证据。摘要筛选仍可能漏掉正文中才交代的相关实验。

没有按论文名称设白名单或黑名单，没有为指定论文单独降低门槛。G1 原先作为独立充分条件的兴趣项已移除，平台信息并入任务判断。问题的文字变化会自动改变 JEV 判断缓存键与筛选档案；已发送论文的去重历史继续生效。

## 2026-10-24 开发验证

使用 TypeSafe 官方 `jev-1.14.0`，按同一配置和同一 0.60 门槛执行，未加入机构过滤或 Top K 限制。

1. 真实论文回归：从用户已有 79 篇译文的 arXiv ID 获取正式英文标题、摘要和分类，79 篇均成功完成，55 篇通过。11 篇已选定的柔顺控制近邻全部保留，包括 SoftMimic、CHIP、LAC、CEER、CEER2、GentleHumanoid、CompliantWBC、Minimalist Compliance Control、OCLO、CoTaP、FALCON。
2. 构造对照：13 个预期相关、13 个预期不相关描述，最终 26 个均符合预期。这些样本用于提示词开发并参与过调试，**不是独立留出测试集**。
3. 样本边界：79 篇是已有阅读资产，未提供完整独立正负标签，也不是随机抽样。通过率不是准确率；上述结果不能用来估计真实部署中的整体精确率或召回率。
