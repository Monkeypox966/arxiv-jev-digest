# 当前人工机构名单

共 **232 家**：S / 100 分 **38 家**、A / 80 分 **132 家**、B / 60 分 **62 家**。分值是用户的阅读偏好，人工名单优先于辅助评估；未收录机构仍可走辅助评估或中性分。

## 本次导入规则

来源为用户提供的《2026 全球具身智能顶尖机构全景名单》。231 条明确分级记录中，230 条可识别机构记录合并为 222 家；新增 166 家，另保留旧名单中未重新分级的 10 家，总计 232 家。

- 同一机构多次出现按最高档合并：智元机器人、RobotEra、Galaxea 的 S / A 冲突统一按 S。
- 原有 13 家分数随用户新分级更新，包括 HKUST、CUHK、TUM、KAIST、NUS、NTU 等升为 S；Harvard 和 UCLA 改为 B。
- “极佳视界之外的世界模型初创团队”属于泛称，没有明确机构身份，不作为固定机构收录。
- 没有 S / A / B 的公司、实验室及泛称不擅自赋分；旧名单已有的保留原分，否则继续由辅助评估 / 中性机制处理。
- 具体校区或研究所的明确名称优先于名字中包含的母校 / 总院。独立合作机构仍分别识别、取最高分。
- 当前按用户要求使用相关性 60% + 机构偏好 40%。
